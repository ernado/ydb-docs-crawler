# Streaming data processing

This section describes the key concepts of stream processing ( [stream processing](https://en.wikipedia.org/wiki/Stream_processing)) in YDB:

- [Streaming queries](streaming-query.md) — a type of query for continuous processing of incoming events. Sources and sinks of data, delivery guarantees, limitations, and query management are described.
- [Watermarks](watermarks.md) — a mechanism for tracking the progress of event processing over time.
