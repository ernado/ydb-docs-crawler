# Deleting a table

Delete the [created](create_demo_tables.md) tables using the [DROP TABLE](../../yql/reference/syntax/drop_table.md) statement.

```yql
DROP TABLE episodes;
DROP TABLE seasons;
DROP TABLE series;
```
