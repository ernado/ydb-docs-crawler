# YQL Tutorial - Overview

From this tutorial, you will learn how to perform basic operations with data in YDB and get familiar with the YQL syntax. A detailed description of this syntax is also available in the [YQL reference documentation](../../yql/reference/index.md).

The tutorial consists of 15 steps:

1. [Creating a table](create_demo_tables.md)
2. [Adding data to a table](fill_tables_with_data.md)
3. [Selecting data from all columns](select_all_columns.md)
4. [Selecting data from specific columns](select_specific_columns.md)
5. [Sorting and filtering](basic_filter_and_sort.md)
6. [Data aggregation](basic_aggregation.md)
7. [Additional selection criteria](conditional_values.md)
8. [Joining tables with JOIN](join_tables.md)
9. [Inserting and updating data with REPLACE](replace_into.md)
10. [Inserting and updating data with UPSERT](upsert_into.md)
11. [Inserting data with INSERT](insert_into.md)
12. [Updating data with UPDATE](update.md)
13. [Deleting data](delete.md)
14. [Adding and deleting columns](alter_table.md)
15. [Deleting a table](delete_table.md)
