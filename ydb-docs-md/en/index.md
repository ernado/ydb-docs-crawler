# YDB Documentation

**YDB** (IPA: \[waɪ diːbiː\], pronounced *wai-di-bi*) is a fault-tolerant distributed SQL DBMS. YDB provides high availability, horizontal scalability, strict consistency, and ACID transaction support. Queries are made using an SQL dialect ([YQL](yql/reference/index.md)).
