# YDB CLI

The YDB CLI provides software for managing your data in YDB.

To use the YDB CLI, first [install](ydb-cli/install.md) it and then set up the [connection and authentication](ydb-cli/connect.md).

For a full description of YDB CLI commands, see the following articles of this section:

- [List of objects](ydb-cli/commands/scheme-ls.md).
- [Getting information about schema objects](ydb-cli/commands/scheme-describe.md).
- [Working with directories](ydb-cli/commands/dir.md).
- [Query execution](ydb-cli/yql-query-overview.md).
- [Streaming table reads](ydb-cli/commands/readtable.md).
- [Working with secondary indexes](ydb-cli/commands/secondary_index.md).
- [Getting a list of DB endpoints](ydb-cli/commands/discovery-list.md).
- [Load testing](ydb-cli/commands/workload/index.md).
