# ADO.NET - .NET Access to YDB

`Ydb.Sdk` is an [ADO.NET](https://learn.microsoft.com/en-us/dotnet/framework/data/adonet/) Data Provider for YDB. It allows programs written in C#, Visual Basic, and F# to access the YDB database server. It is implemented in 100% C# code, is free, and is [open source](https://github.com/ydb-platform/ydb-dotnet-sdk).
