# Installation ADO.NET

Official releases of `Ydb.Sdk` are always available on [nuget.org](https://www.nuget.org/packages/Ydb.Sdk/). This is the recommended way to use `Ydb.Sdk`.

```bash
dotnet add package Ydb.Sdk
```
