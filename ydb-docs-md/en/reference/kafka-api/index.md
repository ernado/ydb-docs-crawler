# Kafka API

YDB supports working with [topics](../../concepts/datamodel/topic.md) using [the Kafka protocol version 3.4.0](https://kafka.apache.org/34/documentation.html). It allows to integrate YDB with applications originally developed to work with [Apache Kafka](https://kafka.apache.org/).

The Kafka API documentation contains the following sections:

- [Authentication](auth.md)
- [Usage examples](examples.md)
- [Kafka Connect](connect/index.md)
- [Constraints](constraints.md)
