# Using Kafka Connect

This section provides configuration examples for popular Kafka Connect connectors to use with YDB.

[Kafka Connect](https://kafka.apache.org/documentation/#connect) is a tool for streaming data between Apache Kafka® and other data stores. YDB supports its topics over the Kafka protocol, so you can use Kafka Connect connectors to work with YDB.

For more information about Kafka Connect and its configuration, see the [Apache Kafka®](https://kafka.apache.org/documentation/#connect) documentation.
