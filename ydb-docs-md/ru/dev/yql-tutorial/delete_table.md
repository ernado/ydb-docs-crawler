# Удаление таблиц

Удалите [созданные](create_demo_tables.md) таблицы с помощью конструкции [DROP TABLE](../../yql/reference/syntax/drop_table.md).

```yql
DROP TABLE episodes;
DROP TABLE seasons;
DROP TABLE series;
```
