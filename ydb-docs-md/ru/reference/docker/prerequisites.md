# Установка Docker для работы с YDB

Прежде чем воспользоваться Docker-образом YDB, необходимо установить и настроить Docker-окружение. Для этого можно воспользоваться официальной документацией:

- [Linux](https://docs.docker.com/desktop/install/linux-install/)
- [macOS](https://docs.docker.com/desktop/install/mac-install/)
- [Windows](https://docs.docker.com/desktop/install/windows-install/)

Альтернативные способы установки, такие как [colima](https://github.com/abiosoft/colima), также допустимы.

Установка самого YDB происходит при [первом запуске](start.md).
