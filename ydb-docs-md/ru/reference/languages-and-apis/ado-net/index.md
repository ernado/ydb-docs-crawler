# ADO.NET — доступ к YDB из .NET

`Ydb.Sdk` — [ADO.NET](https://learn.microsoft.com/ru-ru/dotnet/framework/data/adonet/) Data Provider для YDB, позволяющий программам, написанным на C#, Visual Basic или F#, получить доступ к YDB. Провайдер полностью реализован на C#, является бесплатным и с [открытым исходным кодом](https://github.com/ydb-platform/ydb-dotnet-sdk).
