# Установка ADO.NET

Официальные версии `Ydb.Sdk` всегда доступны на [nuget.org](https://www.nuget.org/packages/Ydb.Sdk/). Это рекомендуемый способ использования `Ydb.Sdk`.

```bash
dotnet add package Ydb.Sdk
```
