# JDBC-драйвер для YDB

JDBC-драйвер для YDB обеспечивает взаимодействие между YDB и приложениями, написанными на Java или других языках программирования, байт-код которых выполняется на JVM. Примеры таких языков — Kotlin и Scala.

## Загрузка {#zagruzka}

Скачайте JDBC-драйвер для YDB с [страницы Releases на GitHub](https://github.com/ydb-platform/ydb-jdbc-driver/releases).
