# Обзор

Для выполнения запросов в YDB CLI рекомендуется использовать следующие команды:

1. [ydb sql](sql.md) — единая команда для выполнения любого SQL запроса, поддерживаемого YDB.
2. [ydb](interactive-cli.md) — переключает консоль в интерактивный режим выполнения запросов.

[Выполнение параметризованных запросов](parameterized-queries-cli.md) описано на отдельной странице.
