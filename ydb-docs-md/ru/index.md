# Документация YDB

**YDB** (читается *вай-ди-би*) — это распределённая отказоустойчивая Distributed SQL СУБД. YDB обеспечивает высокую доступность, горизонтальную масштабируемость, а также строгую консистентность и поддержку ACID-транзакций. Для запросов используется диалект SQL ([YQL](yql/reference/index.md)).
