# Шифрование в YDB

YDB предоставляет два основных подхода к шифрованию пользовательских данных:

- [Шифрование данных при хранении](data-at-rest.md)
- [Шифрование данных при передаче](data-in-transit.md)

Рекомендуется использовать их оба во всех производственных средах, где обрабатываются чувствительные данные.
